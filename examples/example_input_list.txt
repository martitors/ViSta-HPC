# ViSta input list
# Format (one MS per line):
#   <ms_path>  <redshift>  <RA>  <Dec>  [FIELD_ID]  [SPW_IDS]  [NORM]
#
# RA/Dec: position of the source, hh:mm:ss.s  and  dd:mm:ss.s
# FIELD_ID is optional: without it every field is read (phase centre of field 0)
# SPW_IDS is optional: comma-separated list, without it every SPW is used
# NORM is optional and used only by vista.extract
#
# Example:
/path/to/obs1.ms  2.310  12:34:56.7  +12:34:56.7
/path/to/obs2.ms  1.987  12:34:56.7  +12:34:56.7  0  1
/path/to/obs3.ms  2.105  12:34:56.7  +12:34:56.7
